# Retake v0.0.1: the implementation plan

Status: **planned** (2026-10-26). The contract is written ([README](../../README.md),
[docs/cli.md](../cli.md)) and the [proofs of concept](2026-10-26-proofs-of-concept.md) behind it
are done. This record is the plan for building it, as a series of commits on the
`initial-implementation` branch, the first of which adds the command line.

**The README and docs/cli.md define what Retake does, and every commit conforms to them.** This
plan doesn't restate them: it says in what order they're built, what each step has to prove, how
it's tested, and how Puzz moves over. Where the plan and the contract seem to differ, the contract
wins, and the plan is corrected.

## Puzz, Retake's first user

[Puzz Kids](https://apps.apple.com/us/app/puzz-kids/id6749132459) ([puzz.kids](https://puzz.kids))
is an iPhone and iPad app of puzzle games and read-aloud books for children. Its App Store previews
were made by a pipeline built in its own repository, and Retake is that pipeline extracted into a
tool for any app. Puzz is the first app to use Retake, so switching its previews over to Retake is
v0.0.1's final check.

Retake is generic. Puzz is named here, in the plan for Retake's first version, because that check
is part of the plan; it isn't named in Retake's code, its comments, or its other
documentation, and shouldn't be.

## Goal

v0.0.1 is everything the [README](../../README.md) and [docs/cli.md](../cli.md) describe, working
as they describe it, released. Every command does what its section says, every field of every file
is read and acted on, and anything the docs promise that isn't built by the end is taken out of
them rather than left as a stub. It's done when:

1. **Every documented command and field works**, to the contract, with tests, and with what needs
   a device shown on one.
2. **Puzz's previews are made with it.** Puzz's three videos are recorded and cut by Retake, for
   iPhone and iPad, from scenes, sets and edits in Retake's format, replacing the tooling Puzz grew
   for them (`Scripts/PreviewVideo/`: `take.sh` and its recorder, `edit.sh` and its editor,
   `derive-ipad-edit.py`, and `Scripts/launch-heist.sh`), with none of it left in the path.
3. **v0.0.1 is released**, as the README's Install section says: a signed, notarized `retake` on
   GitHub Releases, installed with `mise`, carrying TheInsideJob and Retake's support library.
4. **The repository shows how to use it**: an example app in `Examples/`, with its own
   `retake.json`, sets, scenes and edits, and an integration test that takes it from install to a
   cut video, as a model for a project of one's own.

## How the work is cut

Each step is one commit, small enough to review on its own and complete on its own terms: it
builds, its tests pass, and what it adds works, even when nothing uses it yet. A step that needs a
device to prove it is tested on one, and what it showed is noted against its check below, in the
same commit. A commit that grows too big to review is split rather than squeezed.

- **The docs are the contract.** A command whose commit hasn't landed yet fails saying so, on the
  branch; none does in v0.0.1. A change to what a command does goes into `docs/cli.md` or the
  README on `main` first, as its own commit, and the branch follows it; the branch carries code and
  tests.
- **Everything added is tested**; see [Testing](#testing).
- **The checks are worked off as the commits land.** Each group of commits below lists what it has
  to prove beyond its unit tests, most of it on a device. A commit ticks the checks in its area,
  noting what each showed, or moves one to [After v0.0.1](#after-v001) when the release doesn't
  need it. By the release, no check is left open.
- **Ported code is reshaped, not copied.** Puzz's recorder and editor, and the spikes, are the
  starting point for much of what follows. Each is moved to Retake's file formats and its anchors,
  rather than carried over with its old shape and adapted later.

## After v0.0.1

Known limits the README states, or tests that wait until a release needs them:

- App group containers and defaults suites (`UserDefaults(suiteName:)`): redirecting a group's
  container to a per-take copy, which its extensions don't see, copying a set's files into one,
  and suites in the in-memory defaults.
- A set's `defaults` with values JSON can't express, such as `Data` and `Date`.
- `devicectl`'s newer device commands as set fields or checks: `simulate statusBar` (rather than
  relying on capture to clean it), `settings appearance` for light and dark, `simulate location`,
  and whether its `capture screen-record` could replace the recorder.

## Testing

Every commit tests what it adds, enough to trust that it works and to catch it breaking later. The
tests are for behaviour that could be wrong, not for code that can't be:

- **What's worth a test.** The contract: what each command does, its errors and exit statuses.
  Reading files: every rule a field has, and the message and path for each way of breaking it.
  The logic Retake owns: anchors and their arithmetic, choosing a device, `extends`, per-device
  overrides, conforming an edit, the editor's timing (where each clip, caption and sound lands on
  the video's clock), and metadata written and read back. And every bug fixed, with a test that
  failed before the fix.
- **What isn't.** Restating a constant, a property returning what it was given, or what a library
  already guarantees, such as ArgumentParser parsing a flag. A test that couldn't fail for a real
  mistake isn't written.
- **Unit tests are fast and need no device.** None takes more than a second, and the suite runs
  under a time limit of seconds, so a test that hangs is found at once. What talks to the outside
  — `devicectl`, `codesign`, The Button Heist, AVFoundation's capture — sits behind a small seam,
  so the logic around it is tested against recorded output: `devicectl`'s JSON captured from real
  devices, a step log from a real take. The editor is tested by rendering short compositions from
  small generated movies and checking frames and times, not by eye.
- **Devices are tested on devices.** What only a device can show is checked on one when it lands,
  and noted against its check in this plan. The example's integration test (34) repeats the
  whole path on a device, and is opt-in: it runs when a device is named for it
  (`RETAKE_DEVICE`), and is skipped otherwise, so `swift test` never needs one. Its parts that
  need no device, `validate` on the example project and `cut` from a small take checked in for
  it, run every time.

5. Each video's two edits (`iphone-videoN.json`, `ipad-videoN.json`) become one, with `ipad`

   `soundEffects` folder become `file` paths. `derive-ipad-edit.py` goes.
6. Cut with `retake cut`, compared with the videos Puzz cut itself, and Puzz's tooling removed.

## To discuss

Judgement calls and grey areas met while building, none blocking, each kept going with the choice
described, to settle in review. Each names the commit it came up in.

- **Lists in error paths count from 0, steps in anchors from 1** (3). An error's path follows JSON
  tools and editors, so the third step is `steps[2]`, while an anchor's `step` numbers steps from
  1, so the same step is `{ "step": 3 }`. docs/cli.md's example, `scenes/ipad/create-note.json:
  steps[2]: unknown key "tapp"`, reads either way. The alternative is counting paths from 1 to
  match anchors, at the cost of differing from every JSON tool.
- **`null` for an optional key is an error, not the key left out** (3). `"speed": null` fails with
  "expected a number, found null", since no field means anything by `null`, and a strict reading
  that rejects unknown keys should reject a value that says nothing as well. Treating `null` as
  absent would be friendlier to generated files.
- **A pre-release reads its release's schema** (3). `0.0.1-dev` reads files whose `"$schema"`
  names `0.0.1` without a warning, and `init` will write `0.0.1`'s URL, since pre-releases have no
  published schemas of their own.
- **A `"$schema"` that isn't one of Retake's URLs is accepted without a word** (3), on the view
  that a project may point editors at a local copy; only one of Retake's own URLs naming another
  version, or another kind of file, warns.
- **Values may nest 100 deep** (3). The parser stops there with an error rather than recursing
  further: no Retake file nests more than about ten deep, and Swift Testing's threads overflowed at
  500.
